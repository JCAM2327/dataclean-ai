# Diario — 2026-11-18

## Objetivo
Extender la evaluación de clustering del asesor de modelos con el índice Calinski-Harabasz como métrica adicional de calidad de agrupamiento.

## Acciones realizadas
- Modificación de `dataclean/advisor.py` para calcular y persistir `best_calinski_harabasz` junto a la silueta, inercia y Davies-Bouldin del mejor k.
- Actualización de `dataclean/report.py` para renderizar la nueva métrica en la sección de evaluación de clustering del informe HTML.
- Extensión de `tests/test_advisor.py` para verificar la presencia y tipo de la métrica.
- Elevación de versión a 0.40.0 y documentación en CHANGELOG, ROADMAP (Fase 31) y este diario.

## Resultado
El asesor ahora expone una métrica adicional de validación interna de clustering (mayor valor de Calinski-Harabasz indica mejor separación), disponible tanto en la API como en el informe HTML.
