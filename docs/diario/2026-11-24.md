# Diario — 2026-11-24

## Objetivo
Completar la Fase 36 del ROADMAP: exposición completa y consistente del parámetro de remuestreos bootstrap en la API, sincronización de versiones y documentación.

- Actualización de la versión a 0.45.0 en `__init__.py`, API (`version` y `/health`), README y aserción de pruebas.

- Actualización de ROADMAP.md con la Fase 36 marcada como completada.
- Redacción de este registro diario y actualización del CHANGELOG en formato Keep a Changelog.

## Resultado
El número de remuestreos bootstrap es ahora configurable de extremo a extremo en la API de carga, con versiones alineadas en todo el proyecto. El comportamiento por defecto (20) se mantiene cuando el parámetro no se especifica.
