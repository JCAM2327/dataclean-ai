# Diario de desarrollo — 2026-10-20

## Contexto

Tras completar el soporte de formatos adicionales, el último ítem pendiente de la Fase 6 es la implementación de estrategias de imputación configurables.

## Trabajo realizado

| Área | Detalle |
|------|---------|
| Plan | `build_cleaning_plan` acepta `imputation_strategies` con claves por columna o por tipo (`__numeric__`, `__categorical__`). Estrategias: median, mean, mode, constant. |
| Aplicación | Nuevas acciones `impute_mean` e `impute_constant`. El indicador de ausencia se registra antes de imputar. |
| CLI | Flags `--impute-numeric`, `--impute-categorical` y `--impute-constant-value`. |
| Pruebas | Nueva prueba `test_configurable_imputation_strategies` que verifica media y constante, más el indicador correcto. Suite completa: 31 pruebas. |
| Documentación | CHANGELOG (0.15.0), ROADMAP (ítem marcado), README y versión del paquete actualizados. |

## Decisiones

- Se mantienen las acciones históricas `impute_median` / `impute_mode` para compatibilidad; las nuevas se añaden de forma aditiva.
- La configuración por columna tiene prioridad sobre la de tipo; si no se especifica, se conservan los valores por defecto (mediana / moda).
- El valor constante puede suministrarse en el diccionario de estrategias o vía CLI.

## Resultado de validación

- 31 pruebas pasan.
- El plan generado incluye la estrategia y el valor de relleno en `params` para trazabilidad.

## Próximo paso recomendado

Evaluar la incorporación de estrategias más avanzadas (por ejemplo, imputación por grupo o basada en modelo) o cerrar la Fase 6 y planificar la siguiente.
