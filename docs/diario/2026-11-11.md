# Diario — 2026-11-11

## Objetivo
Exponer las etiquetas de clustering generadas por el asesor de modelos para permitir su consulta directa cuando el análisis no supervisado es viable.

## Acciones realizadas
- Modificación de `dataclean/advisor.py` para incluir el array de etiquetas del mejor k en `clustering_results`.
- Adición del endpoint `GET /datasets/{id}/clusters` en `dataclean/api.py` que retorna las etiquetas persistidas.
- Actualización de pruebas en `tests/test_advisor.py` y `tests/test_api.py`.
- Actualización de versión a 0.34.0, ROADMAP (Fase 25), CHANGELOG, README y `__init__.py`.

## Resultado
Cuando el clustering es evaluado, las asignaciones de cluster quedan disponibles de forma persistida y consultable mediante un endpoint dedicado, facilitando análisis posteriores o visualizaciones externas.

## Siguiente paso concreto
Considerar la descarga de las etiquetas como columna adicional en el CSV limpio o la integración visual de clusters en el informe HTML.
