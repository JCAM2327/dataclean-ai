# Diario — 2026-11-12

## Objetivo
Implementar la descarga formal del dataset limpio en formato CSV, con soporte opcional para incluir las etiquetas de cluster generadas por el asesor.

## Acciones realizadas
- Adición del endpoint `GET /datasets/{id}/download` en `dataclean/api.py` que exige la aceptación previa del plan y retorna el CSV limpio.
- Soporte del parámetro de consulta `include_clusters=true` que añade la columna `cluster` cuando las etiquetas persistidas coinciden en longitud con el dataframe.
- Actualización de pruebas en `tests/test_api.py` para cubrir el requisito de aceptación y la respuesta correcta.
- Actualización de versión a 0.35.0, ROADMAP (Fase 26), CHANGELOG, README y `__init__.py`.

## Resultado
Los usuarios pueden descargar el resultado de la limpieza de forma directa y, cuando el análisis no supervisado produjo etiquetas alineadas, incorporarlas como columna adicional para análisis posteriores.

## Siguiente paso concreto
Considerar la integración visual de los clusters en el informe HTML o la exportación en formatos adicionales (Parquet).
