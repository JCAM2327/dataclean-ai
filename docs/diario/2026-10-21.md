# Diario de desarrollo — 2026-10-21

## Contexto

Tras completar la Fase 6 (limpieza avanzada), el ROADMAP no presentaba ítems pendientes. Se abre la Fase 7 — Preparación de características con el primer entregable: estandarización opcional de columnas numéricas.

## Trabajo realizado

| Área | Detalle |
|------|---------|
| Plan | `build_cleaning_plan` acepta `scale_numeric`. Para columnas numéricas conservadas se añade el paso `scale_standard` con media y desvío estándar (poblacional) calculados sobre los valores observados. |
| Aplicación | Nueva acción `scale_standard` que transforma `(x - mean) / std`. Se preservan NaN originales. |
| CLI | Flag `--scale-numeric` que activa la opción en `analyze` / `analyze_frame`. |
| Pruebas | Nueva prueba `test_scale_numeric_standardization` que verifica generación del paso, parámetros, aplicación correcta y que el comportamiento por defecto permanece inalterado. Suite completa: 32 pruebas. |
| Documentación | CHANGELOG (0.16.0), ROADMAP (Fase 7), README, descripción del paquete y OpenAPI actualizados. |

## Decisiones

- El escalado es opt-in (por defecto `False`) para preservar la compatibilidad con planes y pruebas existentes.
- Se usa desvío estándar poblacional (`ddof=0`) para que el resultado sea determinista e independiente del tamaño de muestra.
- El cálculo de media/std se realiza sobre los datos observados originales (antes de imputación/clipping), coherente con el resto de parámetros del plan que se materializan en la fase de construcción.
- Se requiere al menos 2 observaciones y desvío positivo; de lo contrario el paso se omite.

## Resultado de validación

- 32 pruebas pasan.
- El plan generado incluye justificación y parámetros de trazabilidad.
- La transformación aplicada coincide con el z-score esperado dentro de tolerancia numérica.
