# Diario de desarrollo — 2026-10-08

## Contexto

La detección de variable objetivo (0.3.0) estaba cerrada. El ROADMAP dejaba pendientes la comparación de baselines frente a dos modelos simples y el informe de métricas con advertencias.

## Trabajo realizado

| Área | Detalle |
|------|---------|
| Comparación | `compare_models` ajusta un baseline y dos modelos sobre una partición 75/25 con semilla fija. |
| Clasificación | Baseline de clase mayoritaria, regresión logística y árbol de profundidad 3. Métrica primaria: F1 macro. |
| Regresión | Baseline de media de entrenamiento, regresión lineal y árbol de profundidad 3. Métrica primaria: RMSE. |
| Informe | Ganador, diferencia frente al baseline, features usadas y excluidas, y advertencias de muestra pequeña, desbalance, partición no estratificada o prueba pequeña. |
| Omisiones | No hay objetivo, menos de 8 filas observadas, una sola clase o ninguna feature tras excluir identificadores y constantes. |
| CLI | El informe incluye `modeling`. Con `--apply`, la comparación se ejecuta sobre el dataset limpio. |
| Pruebas | `tests/test_models.py`: clasificación, regresión, ausencia de objetivo, advertencias y features insuficientes. |

## Decisiones

- La imputación de features y el one-hot se calculan solo con el conjunto de entrenamiento.
- Se excluyen identificadores y constantes antes del ajuste; el objetivo no entra como feature.
- El segundo ítem de la fase 2 (informe de métricas y advertencias) se cierra en la misma entrega porque es la salida de la comparación.
- No se interpreta el resultado como validación definitiva: la partición es única y las advertencias de muestra o desbalance permanecen en el informe.

## Resultado de validación

- `pytest`: 13 pruebas aprobadas.
