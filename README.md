# DataClean AI

Plataforma para perfilar datasets tabulares, detectar problemas de calidad, generar y aplicar planes de limpieza, detectar variable objetivo, comparar modelos baseline e informar importancia de variables. Incluye asesor de estrategias de modelado con evaluación de clustering (KMeans) y estabilidad bootstrap configurable.

## Uso básico de la CLI

```bash
python -m dataclean.cli examples/sample.csv --bootstrap-resamples 30
```
